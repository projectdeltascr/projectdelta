## 🛠️ Troubleshooting Common Issues

**❌ Script does not execute after injection**
Sometimes the executor fails to attach properly to the game process.
**Solution:** Close the game completely, reopen your executor, re-inject, and load **Project Delta Script** again. Make sure your executor is updated.

**❌ GUI does not appear on screen**
The **Project Delta Script Gui** can conflict with certain executor overlays.
**Solution:** Press your toggle keybind (default `RightShift`) twice. If it still does not show, change `gui_scale` to `1.2` in the config file.

**❌ Dupe module returns zero items**
The **Project Delta Dupe Script Free** module requires a full inventory load before triggering.
**Solution:** Wait at least five seconds after joining a server before enabling the dupe function.

**❌ FPS drops below playable levels**
Running every feature at once on low-end hardware can strain performance.
**Solution:** Disable `ShowNPCs` in ESP settings and lower `esp_distance` to `300` inside the **Project Delta Script Lua** config.

**❌ Auto Farm path gets stuck on terrain**
Pathfinding in the **Project Delta Script 2026** farm module can occasionally clip geometry.
**Solution:** Teleport to a flat area using the Teleport Hub before starting the auto farm loop.

**❌ Executor crashes on Mac after injection**
Some Mac executors have memory allocation issues with overlay rendering.
**Solution:** Set `NoClip = false` and `FlyEnabled = false` before injecting. Enable them one at a time after the **Project Delta Script Gui** is stable.
